# Trabalho 1 - DSO: Sistema de Clinicas

Sistema orientado a objetos em Python para gerenciar clínicas, pacientes, profissionais de saúde, atendimentos e pagamentos.

## Como executar

Na raiz do projeto:

      python main.py

## Funcionalidades

- **Cadastros:** pessoas (pacientes e profissionais), clínicas e tipos de atendimento
- **Registros:** atendimentos, procedimentos e pagamentos (com pagamento parcial)
- **Relatórios:** clínicas com mais atendimentos, atendimentos mais caros/baratos, procedimentos mais realizados e procedimentos mais caros/baratos

## Estrutura

      model/        classes de dados
      view/         telas (entrada e saída no terminal)
      controller/   controladores (regras de negócio)
      exceptions/   exceções personalizadas
      main.py       ponto de entrada
